# 방언(사투리) 자막 지원 계획 (이슈 #25)

## 현재 상태 (실측 전 — 추정 금지 원칙에 따라 측정부터)

- STT는 Qwen3-ASR 1.7B(+Whisper 교차 검증). 표준어 기준으로 선정·실측했고
  **방언 정확도는 아직 측정한 적이 없다.**
- 이미 있는 지렛대: `--prompt`(도메인 어휘 바이어스), 고유명사 사전(치환),
  AI 문맥 교정(문맥 기반 오인식 교정), 크로스체크(엔진 간 불일치 검출).

## 단계 계획

### 1단계 — 실측 (선행 필수)
경상·전라·제주 등 지역별 실제 콘텐츠 2~3분씩 확보해 현재 파이프라인의
단어 오류율을 잰다. **측정 없이 모델 교체·튜닝으로 넘어가지 않는다**
(SenseVoice 사례: 소문 좋았지만 실측에서 기각).

- 판정 기준: 표기 그대로 받아쓰기(사투리 어휘 보존)가 되는가 vs
  표준어로 "번역"돼 버리는가 — 사투리 콘텐츠는 **표기 보존**이 가치다.

### 2단계 — 싼 개선부터
1. **방언 프롬프트 프리셋**: 언어 설정에 "한국어(방언 보존)" 옵션 —
   `--prompt`에 지역 어휘·어미 예시를 실어 바이어스. 코드 변경 최소.
2. **지역 어휘 사전 팩**: 고유명사 사전에 지역별 프리셋(내장 목록) 추가.
3. AI 문맥 교정의 방언 모드 — 교정이 사투리를 표준어로 "고치지" 않게
   가드 프롬프트.

### 3단계 — 실측이 나쁠 때만
- 방언 파인튜닝 모델 조사(AI Hub 한국어 방언 데이터셋 존재 — 학습은 대형 작업).
- Whisper 계열 방언 성능 대조 실측.

## 리스크
- 방언 정답 데이터 확보가 병목 — 사용자(테스터) 제공 콘텐츠가 가장 현실적.
- "사투리를 표준어로 자동 변환"과 "사투리 표기 보존"은 반대 요구 —
  옵션으로 갈라야 한다.
