# TypeCut Pro 기능 전수 점검

> v0.13.4 · 점검일 2026-08-11
>
> Swift 13,665줄(50파일) · 엔진 Python 22모듈 · 테스트 Swift 226 / 엔진 162

앱과 엔진의 모든 기능을 훑고 각각이 지금 실제로 어떤 상태인지 적었다.
**"만들었다"가 아니라 "지금 사용자 손에서 동작하는가"**를 기준으로 판정했다.
그래서 코드가 있어도 화면이 없거나 실효가 없으면 동작으로 치지 않았다.

## 화자 분리

| 기능 | 상태 | 비고 |
|---|---|---|
| 고정밀 Core ML (FluidAudio) | 동작 | 2026-08-10 완성. HF 토큰 · 런타임 네트워크 불필요, 115초 오디오 2.9초. **네트워크를 완전히 차단한 상태에서 완주함을 실증.** 코덱스 리뷰 8차 통과 |
| 기본 분리 (resemblyzer) | **한계** | 실측 한계 도달 — 같은 화자 유사도 0.84 vs **다른 화자 0.78**(마진 0.058). 정답을 알려준 지도 분류조차 82.8%. 클러스터링을 바꿔도 안 낫는다(친화도 정제 +0.4%, AHC −25%p) |
| 모델 설치 UI | **없음** | 지금은 이 맥에 이미 있는 모델을 쓴다. **다른 사용자 맥에는 없어서 고정밀이 조용히 기본 분리로 내려간다.** manifest · 해시 검증 · 설치 상태 조회(`--check`)는 이미 있고 UI만 없다 |
| 화자별 색상 · 비디오 롤 · 스토리라인 묶기 | 동작 | 화자 번호를 FCP 롤에 매핑해 색이 자동으로 붙는다 |
| 겹침 발화 2줄 자막 | **없음** | 요청받았으나 착수 전. 오프라인 파이프라인이 겹침 구간을 따로 내주지 않아 계약상 자리(`overlap_segments`)만 잡아 뒀다 |
| 화자 이름 편집 | **없음** | 데이터 자리(`speakers`)는 프로젝트 문서에 있고 화면이 없다 |

## 지금 판단이 필요한 것

1. **48.7초 · 53.4초가 실제로 두 사람인가**
   오디오를 들어야 판정된다. 두 사람이면 자막 분할 정책만 고치면 되고, 한 사람이면 분리 자체를 더 파야 한다.

2. **모델 설치 UI를 언제 할 것인가**
   이게 없으면 고정밀 화자 분리는 개발 맥에서만 동작한다. 검증 · 상태 조회는 이미 있고 화면만 붙이면 된다.

3. **잠든 도움말 20개를 깨울 것인가**
   번역까지 끝난 문구다. 새로 쓸 필요 없이 붙이기만 하면 옵션 설명이 생긴다.

4. **죽은 AI 자막 분리를 지울 것인가**
   채택률 0%로 실측됐다. 남겨 두면 다음 사람이 다시 조사하게 된다.
