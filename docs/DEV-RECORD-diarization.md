## 최종 상태 (v0.13.22 기준)

- **실측 정확도: 앱 실출력 91.5%, CLI 93.1%** (사용자 제공 정답 58~59단어, 테슬라 리뷰 5.7~35.3초 구간)
- 남은 오차의 정체 (전수 분석 완료):
  - 겹침 구간(어머·많이, 10초 부근) — 두 사람이 동시에 말해 단일 정답이 없는 자리. "말이 겹칠 때 2줄" 기능이 담당.
  - 1초 즉답(뭐라고 놀려, 18초) — 확신 문턱(양쪽 ≥1.4초) 의도적 보류. 문턱을 낮추면 "이건 내 차인데" 찢김이 재발함을 테스트로 확인.
  - 수동 백스톱: 대본 우클릭 → 화자 변경 / 화자 이름 변경 (v0.13.17).

## 아키텍처 (엔진 `silence_cutter/diarize.py` + `engine.py`)

1. **음향 엔진**: FluidAudio Offline Core ML (`tools/diarize-cli`, SPM 0.14.4) — pyannote community-1 분할 + WeSpeaker 임베딩 + PLDA/VBx. 모델 21MB 번들(`diarize-models`, CC-BY-4.0, NOTICE.txt), manifest SHA-256 검증, 완전 오프라인(sandbox-exec 네트워크 차단으로 증명). HF 토큰 불필요.
2. **2-패스 창 스위프** (`_window_sweep`): 전체 1차(성문 중심 확보) + 24초 창 지역 재분리, 코사인으로 신원 되붙임(`_map_local_speakers`, 용량 제한 그리디). 근거 실측: 전역 클러스터링은 15.5~33.5초의 빠른 교대를 0턴으로 뭉갰지만, 같은 모델에 그 구간만 주면 4/6턴을 찾았다.
3. **문장 우선 배정 v6** (`_speaker_runs`): 종결어미/0.6초 쉼/0.2초 쉼+교대/무쉼 확신 교대(양쪽 ≥1.4초, ±0.6초 단어끝 스냅)로 문장을 먼저 나누고, 문장 전체를 발화시간 우세 화자에게 배정. **문장 찢김이 구조적으로 0.** 단어별 배정 + 경계 규칙 5종(v1~v3)은 찢김을 계속 흘려 폐기 — 경계 규칙을 다시 덧대지 말 것.
4. **캐시 자동 무효화**: 알고리즘 지문(pyc 헤더 16바이트 제거한 코드 해시)이 캐시 키에 들어감 — 수동 버전 올림을 잊어 개선이 화면에 안 닿던 사고 2회 후 도입.

## 버전 연대기

| 버전 | 내용 | 결과 |

## 실측으로 기각/확정한 것

- **resemblyzer(구 baseline)**: 임베딩 마진 0.058뿐(같은 화자 0.84 vs 다른 화자 0.78), 창 클러스터링 81.1% = 임베딩 한계. 정제·AHC·창 크기 조정 전부 무의미.
- **pyannote(파이썬)**: gated 모델 + HF 토큰 필요 → 사용자 대부분 못 씀 — 기각. HQ 토글은 토큰 게이트 잔재 때문에 앱에서 한 번도 실행된 적 없었음(발견 후 토글 제거, Core ML 내장).
- **SenseVoice/FunASR**: 세그먼트 파이프라인 9.3x < Qwen 12.9x, 한국어 품질 열세 — 기각.
- **STT 확정**: Qwen3-ASR + Whisper 2중 검증(cross-check) 유지.
- **두 음향 엔진의 일치율 95.5%** — 불일치는 전부 1~2어절 맞장구. 강한 모델로 갈아타도 자막 모양은 거의 같다 → 남은 개선은 분할 정책·보정 UI의 영역.

## 치명 버그 기록 (재발 방지)

1. **앱에서 Core ML이 한 번도 안 돌았다** (v0.13.17까지): 개발 빌드는 엔진을 소스 레포에서 돌리는데 `_diarize_bin()`은 "엔진 옆"만 탐색 → 매 분석 `binary_missing` → 약한 폴백. CLI 측정만 통과하고 앱 실사용과 괴리. v0.13.18에서 `FCPA_DIARIZE_BIN` 번들 경로 명시로 해결. **교훈: 앱 경로는 로그의 `창 스위프`/`폴백` 라인으로 실측 — CLI 통과로 앱 동작을 추정하지 말 것.**
2. **캐시 재사용이 개선을 가림**: 규칙 추가 후 ALGO_VER 올림을 잊어 옛 결과 재사용 → 자동 지문으로 해결.
3. **HF 토큰 키체인 잔재**: 재빌드마다 키체인 암호 요청 — 토큰 코드 전면 제거(v0.13.18).
